# Neural Network From Scratch

## Introduction

I implemented a neural network from scratch using Python and NumPy.

I wanted to understand what actually happens inside a neural network during training instead of just using a library that does everything for me.

## What I Did

- Loss calculation
- Backpropagation
- Gradient descent
- Updating weights and biases
- Training the neural network

## What I Learned

This project gave me a better understanding of how a neural network actually learns.

I also had to deal with a whole lot of errors while building it, but debugging them helped me understand what was actually going on.

## Technologies Used

- Python
- NumPy
- Matplotlib
