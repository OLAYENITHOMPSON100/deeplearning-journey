# Handwritten Digit Classification Using ANN

## Project Overview

This project uses an Artificial Neural Network (ANN) to classify handwritten digits from 0 to 9 using the MNIST dataset.

## Purpose

The purpose of this project is to understand how an Artificial Neural Network learns patterns from image data and uses those patterns to classify handwritten digits.

Through this project, I explored how image pixels are represented numerically, how a neural network processes these values, and how weights and biases are adjusted during training.
  
## Technologies Used

- Python
- TensorFlow/Keras
- Numpy
- Matplotlib

## Methodology

1. Loaded the MNIST dataset.
2. Split the dataset into train and test set
3. scaled the image data.
4. Flattened each 28 × 28 image into 784 input features.
5. Built an Artificial Neural Network.
6. Trained the model to classify digits from 0 to 9.
7. Evaluated the model's performance.

## What I Learned

- How image data is represented numerically.
- How an ANN processes input features.
- The roles of weights and biases in learning.
- How activation functions help neural networks learn patterns and how different activation function can give you different accuracy.
- How a neural network makes classification predictions.
